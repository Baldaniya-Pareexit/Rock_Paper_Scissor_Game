# Rock_Paper_Scissor_Game 🎮

This is a simple Python implementation of the classic Rock-Paper-Scissors game. It allows a user to play against the computer in a command-line interface.

## 📝 **How It Works:**

The game asks the user to input their move: 'Rock', 'Paper', or 'Scissor'.

The computer randomly selects a move from the same list.

The winner is determined based on the standard rules of the game.

## 🧠 **Game Rules:**

Rock crushes Scissors 🪨✂️

Paper covers Rock 📄🪨

Scissors cuts Paper ✂️📄

## ▶️ **How to Run:**

Make sure you have Python installed on your machine. Then run the following command in your terminal:

python Game--Rock_Paper_Scissor.py

## 📂 **File Structure:**

Game--Rock_Paper_Scissor.py  # Main game script

## 💡 **Example Output:**

Enter your move = 'Rock','Paper','Scissor' : Rock
User_choice = Rock
Computer_choice = Paper
Result = Paper covers Rock : Computer win
